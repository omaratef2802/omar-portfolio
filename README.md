# Omar Atef — Developer Portfolio

A personal, multilingual developer portfolio built with **Angular 22**, **TypeScript**, and custom CSS.

## Features

- Responsive creative dark-first design with light mode
- Accent color presets and custom color picker
- English, Arabic (RTL), and Italian content
- Persistent language, theme, and accent preferences
- Project highlights for TaskFlow and PathwayEd
- Direct email, LinkedIn, GitHub, and WhatsApp links
- Reduced-motion support and semantic navigation

## Run locally

```bash
npm install
npm start
```

Open `http://localhost:4200`.

## Production build

```bash
npm run build
```

The production output is generated under `dist/omar-portfolio/browser`.

## Deploy to Vercel

Import this repository in Vercel. Use `npm run build` as the build command and `dist/omar-portfolio/browser` as the output directory.
